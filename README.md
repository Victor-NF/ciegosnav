# CiegosNav

Aplicación web para iPhone (se instala desde Safari) que guía a pie por voz y ayuda a mantener la dirección.

Estado: versión 0.1, experimental. La función de alineación no está validada en dispositivo.

- Rutas a pie: OpenStreetMap (Nominatim y routing.openstreetmap.de).
- Pruebas de la lógica: `npm test` (Node 20 o superior).
- Ayuda y pruebas seguras: `ayuda.html`.
